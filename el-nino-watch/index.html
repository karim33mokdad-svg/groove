Synthesis

Live variables combined into risk indices, with every factor shown

This is a transparent heuristic, not a validated forecast model. It combines the live variables below — temperature against normal, rainfall against normal, humidity, wind, and the ENSO phase weighted by each region's real teleconnection strength — into 0–100 indices. Every contributing term is listed so you can see exactly why a number moved, and disagree with it. Regions where ENSO is a weak predictor (Lebanon, Türkiye) get a correspondingly small ENSO term by design.

How this dashboard works

Everything refreshes from live sources each time you open the page (and every 15 minutes while it's open). Nothing is stored on a server — the watch list and cached climatology live in your browser.

ENSO state

Six points across the Niño 3.4 box (5°N–5°S, 170°W–120°W) are sampled for sea-surface temperature from Open-Meteo's marine model. The average is compared to the standard 1991–2020 monthly climatology for that box to give an anomaly, and a 90-day mean approximates the ONI's 3-month smoothing. This is an indicative estimate: the model SST carries its own bias, so it can differ from NOAA CPC's official ONI by a few tenths. Pin the official value from CPC when it updates (monthly) and it will be shown alongside — the phase label then follows the pinned value.

Local anomalies

For each location the daily normal is built from the ERA5 archive over 2010–2024, smoothed over a ±7-day window around each calendar day. "+3.1° vs normal" means today's mean temperature is 3.1 °C above that 15-year normal for this date. Rainfall is compared the same way, as a percentage of the normal 7-day total.

El Niño lens

The regional notes describe how each area typically behaves in the current ENSO phase, drawn from established teleconnection research, with an explicit confidence level. Indonesia and Thailand have strong, well-documented ENSO signals. The Gulf is moderate. Lebanon and Türkiye are weak — the North Atlantic Oscillation and Mediterranean storm track usually matter more there, and the notes say so.

Watch items

The strip at the top is computed live from the forecast: extreme heat, heavy rain, damaging gusts, large temperature anomalies and unusually dry or wet weeks across every location being tracked.

Pin the official ONI

NOAA CPC publishes the Oceanic Niño Index monthly. Enter the latest value here and the dashboard will show it as the authoritative number and label the phase from it. Open the CPC table.
